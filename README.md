# Multimodal Physiological Phenotyping of Obesity

Proof-of-concept repository for multimodal physiological phenotyping using data science and interpretable AI.

## Modalities
- Body composition
- Heart rate variability (HRV)
- Muscle oxygen saturation (SmO2 / NIRS)

## Important
All data in this repository are **fully simulated**. They do not represent real patients and are not derived from VIDANTE IPS.

## Run
```bash
pip install -r requirements.txt
jupyter notebook
```

Open `notebooks/01_simulated_multimodal_phenotyping.ipynb`.
